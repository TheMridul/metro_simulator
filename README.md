# Metro Simulator

A command-line tool that simulates Delhi Metro timings and route planning across the Blue Line, Blue Line Branch, and Magenta Line.

## Features
- Computes next metro arrival times for any station and direction.
- Generates complete trip plans, including route with minimum interchanges, direction detection, and transfer handling.
- Accepts custom time input.
- Handles service-hour rules.

## Service Rules
- Operating window: 06:00 to 23:00.
- If the current or input time is earlier than 06:00, the simulator returns the first possible metro of the day.

## Meta Data Files
Station datasets and timing data are loaded from:
- metro_data.txt (a plain text file listing stations, line codes, and distances; each line follows the format: `<station_id>,<station_name>,<line_code>,<distance_from_start>`.  
  Example:  
  ```
  1b,Noida City Centre,Blue,0
  2b,Noida Sector 15,Blue,1.2
  1m,Janak Puri West,Magenta,0
  ```
)
- Internal travel-time offsets generated by the program.

- Adds a fixed 4-minute interchange delay (currently hardcoded and not configurable).

## How It Works
- Loads station data with `readSection`.
- Computes offsets with `calcOffset`.
- Generates metro timings with `calcTimings`.
- Performs routing and interchange logic using `tripPlanner`.
- Adds a fixed 4-minute interchange delay.

## Modes
### Metro Timings
Shows the next upcoming metro timings for a selected station.

### Trip Planner
Computes the fastest route between two stations with timing details.

## Usage
Run:
```
python metro_simulator.py
```

## Station ID Format
- Blue Line: IDs end with 'b' (e.g., `1b` for Noida City Centre, `14b` for Rajiv Chowk, `42b` for Dwarka Sector 21)
- Blue Branch: IDs end with 'bb' (e.g., `1bb` for Vaishali, `4bb` for Kaushambi)
- Magenta Line: IDs end with 'm' (e.g., `1m` for Janak Puri West, `26m` for Botanical Garden)

## Notes
- If time is before 06:00, the first available metro is returned.
## Assumptions
- Travel times use frequency-based estimates:
  - Peak hours (08:00–11:00 and 17:00–20:00): 4-minute frequency.
  - Normal hours (all other service times): 8-minute frequency.
- Interchange wait is fixed at 4 minutes.
- Service starts at 06:00. Any time before returns first metro.
- Distances and offsets are used exactly as provided in metro_data.txt.
- First metro timings are assumed to start at 06:00 from the starting and ending station of each line.
## Data Source
- Station list and distances taken from [delhimetrorail.info](https://www.delhimetrorail.info/).
- Timing offsets computed programmatically in metro_simulator.py.
- Travel time b/w two consecutive stations is derived by assuming 2min for every 1km distance.
